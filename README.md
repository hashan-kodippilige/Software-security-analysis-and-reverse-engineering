## Overview

This repository contains labs and projects completed as part of a **Software Security Analysis** course in the **Master of Science in Cybersecurity** program at **Minnesota State University Moorhead**.

The work spans the full offensive and defensive software security spectrum — from writing and compiling C and Python programs, to disassembling binaries in Ghidra and IDA Pro, analysing malware behaviour with Sysinternals, patching vulnerable executables, and testing web applications with OWASP ZAP.

## Technologies Implemented

### Secure Software Development
- C programming with input validation and secure coding practices
- Python scripting and Portable Executable (PE) creation with PyInstaller
- Assembly language programming and compiler output analysis

### Reverse Engineering & Binary Analysis
- Static analysis with **Ghidra** and **IDA Pro**
- Control flow analysis and disassembly interpretation
- Binary patching and bug identification
- PE file structure examination

### Malware & System Analysis
- Process and file system monitoring with **Process Monitor (Procmon)**
- Startup persistence analysis with **Autoruns**
- Registry and Windows internals investigation
- Malware behaviour documentation

### Web Application Security
- Vulnerability scanning with **OWASP ZAP**
- Web application vulnerability assessment
- Security countermeasure identification

### Vulnerability Research
- Static and dynamic analysis workflows
- Software protection mechanism analysis
- Threat identification and mitigation strategies

## Key Accomplishments

- Developed C and Python programs and analysed their compiled output at the assembly level
- Reverse engineered binaries using Ghidra and IDA Pro to map control flow and identify logic
- Created Portable Executables from Python scripts and analysed their PE structure
- Monitored live process activity, registry changes, and file system events with Sysinternals
- Identified and patched vulnerabilities in compiled binaries
- Performed web application security assessments using OWASP ZAP
- Conducted static and dynamic malware analysis and documented behaviours
- Evaluated software protection mechanisms and proposed security countermeasures
