# Software Security Analysis and Reverse Engineering

## Overview

This repository contains hands-on labs and projects completed as part of Software Security Analysis coursework.

The work focuses on secure software development, reverse engineering, vulnerability assessment, binary analysis, malware investigation, software protection mechanisms, and web application security testing.

Projects were completed using Python, C, Assembly Language, Ghidra, IDA Pro, OWASP ZAP, Microsoft Sysinternals, GCC, Visual Studio Code, and Kali Linux.
